# NPT Equilibration – Unknotted YbeA

This directory contains the NPT equilibration files for the unknotted YbeA (YbeA*) protein system.

**Software:** GROMACS
**Force field:** CHARMM36
**Water model:** TIP3P
**Ensemble:** NPT

**Objective:** To equilibrate the unknotted YbeA system under constant pressure and temperature before production molecular dynamics.
