# NVT Equilibration – Unknotted YbeA

This directory contains the NVT equilibration files for the unknotted YbeA (YbeA*) protein system.

**Software:** GROMACS
**Force field:** CHARMM36
**Water model:** TIP3P
**Ensemble:** NVT

**Objective:** To equilibrate the unknotted YbeA system at constant volume and temperature before NPT equilibration.
