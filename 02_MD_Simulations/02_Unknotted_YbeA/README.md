# Unknotted YbeA – Molecular Dynamics Simulations

This directory contains the molecular dynamics simulation files for the engineered unknotted variant of YbeA (YbeA*).

**Protein:** Unknotted YbeA (YbeA*)
**Reference protein:** YbeA (PDB ID: 1NS5)
**Topology:** Unknotted variant
**Simulation software:** GROMACS
**Force field:** CHARMM36
**Water model:** TIP3P

**Objective:** To investigate the structural stability and conformational dynamics of unknotted YbeA and compare its behaviour with native trefoil-knotted YbeA.
