# NVT Equilibration – Knotted YbeA

This directory contains the input parameters and output files for the NVT equilibration of native trefoil-knotted YbeA.

**Simulation software:** GROMACS
**Force field:** CHARMM36
**Water model:** TIP3P
**Ensemble:** NVT (constant number of particles, volume and temperature)

**Purpose:** To equilibrate the system at the target temperature before proceeding to NPT equilibration.
