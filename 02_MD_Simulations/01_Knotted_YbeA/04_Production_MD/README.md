# Production Molecular Dynamics – Knotted YbeA

This directory contains the production molecular dynamics simulation files for native trefoil-knotted YbeA.

**Protein:** YbeA (PDB ID: 1NS5)
**Simulation software:** GROMACS
**Force field:** CHARMM36
**Water model:** TIP3P
**Ensemble:** NPT
**Simulation duration:** 100 ns
**Time step:** 2 fs

**Objective:** To investigate the structural stability and conformational dynamics of the trefoil-knotted YbeA protein under equilibrium conditions.

The production trajectory is used for subsequent structural and dynamical analyses.
