# Knotted YbeA – System Preparation

This directory contains the initial structure and system preparation files for the native, trefoil-knotted YbeA protein.

**Protein:** YbeA  
**PDB ID:** 1NS5  
**Topology:** Trefoil knot  
**Knot region:** Approximately residues 71–119  
**Simulation software:** GROMACS  
**Force field:** CHARMM36  
**Water model:** TIP3P

The prepared system is used for subsequent molecular dynamics simulations to investigate the structural stability and dynamics of knotted YbeA.
